# DSH 宿主插件补丁

这里维护我们实际开发的官方内置插件修复，属于可重复的补丁源码，不是可由 DSH 插件管理器直接安装的 Cordis 插件。独立插件的归属和后续开发约定见 [DSH 插件管理](../dsh-plugins.md)。

| 补丁 | 官方基线 | 范围 |
| --- | --- | --- |
| [目标动作与图片草稿](goal-image-drafts/README.md) | DSH `0.2.1-rc.4`，并精确校验归档和模块 SHA256 | 恢复按钮异常锁死、blocked 恢复入口；切会话及刷新时的附件草稿保留 |

源码、基线指纹、构建工具、安装/回滚脚本和回归测试进入 Git。官方完整 bundle、`node_modules`、`.artifacts`、安装包、备份以及任何个人配置不进入 Git。修复归属上游时仍保留来源，不冒充独立插件，也不自动挂入用户 profile。

补丁是临时兼容维护：宿主升级后先检查上游是否已修复，再重新评估、测试与更新基线；不能仅修改版本号或跳过哈希检查强行安装。当前维护工具仅为已核实的 Windows DSH NEXT 构建准备，不提供修改其他签名应用或绕过其完整性机制的支持。
