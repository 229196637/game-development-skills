# 有 UI 时的模块规划

先判断本模块是否需要玩家可见界面、HUD、弹窗或交互；没有 UI 则在范围中说明不涉及，不创建空 ui.md、View 或 HTML。需要 UI 时在 docs/文档/<模块>/设计/<任务>/ui.md 单独记录，由任务入口及模块架构/接口/流程链接。代码与文档的端归属分别判断：服务端业务的 UI 仍运行在客户端。

## 按业务逻辑执行端选择目录

| 业务逻辑归属 | 客户端手写代码布局 | UI 职责与边界 |
| --- | --- | --- |
| 客户端执行业务逻辑 | client/<模块>/View/（沿用项目现有 view/ 大小写） | 在对应模块内的 View 层集中放窗口、组件和表现/交互适配；业务状态、规则和流程保留在该模块逻辑层，UI 通过实际模块接口及领域事件协作 |
| 服务端执行业务逻辑 | client/<模块>/，UI 代码直接在这个模块文件夹内 | 客户端仅承载该业务的展示、输入、必要客户端状态与网络适配；无需强制再套 View，不复制服务端业务规则、判定或权威状态 |

这里 View 是模块的 UI 层目录/归属，不强制增加一个空 View 基类或固定数量的包装类。使用语言实际模块与命名空间规则。服务端业务的客户端网络 Service 仍单独负责协议，窗口不直接注册、解析或授权网络消息。混合模块按具体职责标明权威端，本地业务与服务端业务分别映射；不以 UI 所在端误判业务逻辑归属。

优先遵循用户指定的以上划分；项目旧技能若统一要求所有模块都放 view/，本规则对服务端逻辑模块的客户端 UI 布局是明确例外。不要因此移动无关旧模块。

## 复用当前框架

先查项目实际 UI 文档/API、模块约定和一个现有窗口；足够且有效时不重复扫描。需要实现核对时查看对应源码。项目 client-dev、fgui-development 等规范可用时读取相关部分；旧规范与当前实现不一致时记录差异，不生搬未存在的 API。

- 沿用已有 UIManager、窗口登记/生成注册表、窗口基类、资源绑定、统一适配、输入分发和生命周期。当前项目示例使用 UIManager.Open(UiWindowId, args)、[UiWindow]、WindowBase 及 OnCreate/OnOpen/OnShow/OnHide/OnDispose；其他项目用真实等价契约，不硬编码这些名字。
- 窗口通过管理器打开，不绕过管理器另建独立 Canvas/Root、更新入口或资源生命周期；模块手写 UI 不放跨模块 UI 运行时根目录。
- 区分手写业务 UI、FGUI/其他工具的源资源和自动生成绑定。记录实际输出路径及发布顺序，不手改生成文件。
- ui.md 明确业务 owner、状态来源、打开/关闭触发、按钮调用接口、领域事件、网络响应和刷新路径；回包经网络适配转成业务状态/领域事件，再由 UI 更新。
- 订阅、输入和资源按真实生命周期成对管理；缓存关闭/重开后的行为、异步迟到结果及重复刷新以当前框架能力为准。加载和暂停期间 UI 保持可操作，不依赖停止的业务世界帧。
- 公开 UI 函数仍使用原语言 API 声明，只记录公开函数；控件、属性、事件及布局在 ui.md 中说明，不塞进 API 文件。

## HTML 设计稿

UI 规划必须链接一份可直接打开的 HTML 设计稿，默认保存为同模块 ui-preview.html；ui.md 正文用相对链接指向它，meta.links 同步登记，任务入口通过 ui.md 导航。用户需要时打开该 HTML 供查看，不只提供截图或描述。

HTML 表达本次已确认的页面/HUD/弹窗布局、主要控件与交互；覆盖正常、加载、空、失败或禁用等本模块实际需要的状态，可用简单状态切换查看。样式、数据和必要脚本尽量内置，使本地直接打开即可查看，不依赖新服务、构建或联网安装。HTML 可用本地模拟状态，不连接游戏、发送真实请求或修改业务数据；在稿内简短标明模拟数据与已实现程度。

尺寸、锚点/安全区、文本溢出、按钮状态与显示内容对应 ui.md。未明确的视觉/业务决策标为待确认，不额外创造玩法。HTML 是可 review 的设计参考，不替代正式 FGUI/引擎资源；开发时把实际差异回写 ui.md 和 HTML，不以能打开 HTML 声称游戏 UI 已完成。

## 交付与验收

在任务唯一 TODO 中路由 UI 设计、资源/绑定、模块 UI 实现和集成验收，关联业务/API/网络前置项；不在 ui.md 复制 TODO 状态。ui.md 至少包含本模块的依赖架构图与关键交互流程图，或明确链接本模块已有图及 UI 对应节点，不用任务总图替代。

检查 HTML 本地打开、链接可达、布局可读和必要交互；正式 UI 验收覆盖打开/关闭/重开、状态刷新、输入、资源/订阅清理及实际分辨率适配。服务端逻辑模块还验证等待响应、拒绝/失败与迟到回包；只有本次实际验证的内容可报告通过。
