# 风格档案

风格位于 `styles/<style-id>/<version>/style.md`，图像参考放同级 `references/`。风格档案既供人查阅，也供后续生图直接复用；只列“仙侠、精致”不足以稳定风格。

按 [风格模板](../assets/style-template.md) 记录：ID/版本、定位、完整描述、色彩与材质、光照与视角、轮廓与细节密度、边缘/阴影/光效、主体/背景/公共底座的区别，以及固定提示词片段和禁止项。链接代表图片；文字约束与图片冲突时先指出具体冲突，不静默选择。

后续提示词原样引用版本的固定片段，再增加素材用途、主体、构图、透明度和分层约束。不要只引用风格名字。沿用同一风格时不覆写原描述；有意改变关键视觉特征则建立新版本，旧资源继续引用旧版本。用户未授权改变美术方向时，新增素材匹配现有档案。

生成结果检查回到相同档案核对，不以模型自行补充的特征反向覆盖风格。真实观察与设计目标分别说明，例如“观察：生成图偏暖；目标：冷蓝背景，金色仅作点缀”。
