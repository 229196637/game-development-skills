# 讨论风格

从当前需求和已有资料开始，不用固定问卷阻碍简单决定。围绕实际差异提问：写意或精细、二维或体积、严肃或可爱、色彩明度、装饰密度、材质、目标玩家、哪些旧效果不喜欢。已有明确答案沿用，未知且影响画风的偏好再问。

比较图片保持相同功能与构图，改变真正的艺术语言，不能只换颜色就称为不同风格。可以用几个代表物件，不强制每次生成完整游戏界面。先读图，说明各版实际差异与不足，保留用户反馈；不自动采用代理喜好或某个默认审美。

讨论可以纯文字；需要看图时使用已有参考或当前 imagegen。预览阶段只生成风格效果，不批量生产运行素材。候选数量按需求选择，不强制三版或六版。一次一版或多版均可，受已有生图技能规则约束。

用户说“就用D写意水墨，后面按这版做”可记录确定；“D好像不错，再看看”仍是讨论。确认图中还有用户要求修改的细节时，先修正并展示，不把未展示的目标当认可参考图。定稿记录必须对应用户实际认可的图片版本。

改变已用于素材生产的风格时，新建版本或新风格ID，保存旧图与旧描述；说明受影响的生产任务，但不自动重做全部旧素材。定稿入口指向当前认可版本，历史决定在对应讨论任务保留。对用户明确授权的局部修正，不机械增加第二次审批。
