# 逐类任务记录

每类一份 MD，参照 [类任务模板](../../assets/templates/class-task.md)。meta 使用 JSON 值的 YAML（字符串带引号，列表用方括号），使工具无额外依赖读取。

| 字段 | 含义 |
| --- | --- |
| task_id | 本任务根下唯一稳定 ID |
| class | 实际类名或模块/脚本单元名 |
| document | 相对本任务 MD 的对应文档路径；必须存在 |
| status | todo / doing / blocked / completed |
| depends_on | 当前任务根内前置 ID 列表，无则 [] |
| required_tests | 必须实际通过的测试 ID 列表，至少一项适当验证 |
| updated | 当前更新时间，YYYY-MM-DD HH:mm:ss ±HH:MM |

正文固定为 `## 目标`、`## 任务内容`、`## 测试过程`，最后一节必须是测试过程。目标简述交付；任务内容用 `- [ ]` / `- [x]` 写实现工作，并链接对应文档。任务不包含职责/API/设计/目录树/流水线等正文，文档自身的 meta 依赖也不复制进来。

测试表列为 `时间 | 测试 ID | 命令/步骤 | 预期 | 实际 | 结果 | 证据`。结果 passed/failed/not-run；证据填写实际日志/报告/版本与输出位置，不能凭空写通过。每个必需测试用最后一条记录判断；失败后追加成功，不覆盖失败历史。底部可链接独立证据，但不另起后续章节。执行者勾选任务内容；工具记录测试和状态，completed 必须同时满足前置、工作项和必需测试。
