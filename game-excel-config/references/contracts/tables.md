# 配置契约
每个字段必须有说明清楚的注释，规划字段字典、Excel 说明行/列与生成配置的字段注释同步维护；明确用途、单位、填写格式、真实约束、默认/特殊值及外键目标，不能只重复名字。详见 [字段与导出](fields-and-export.md)。
每张表明确用途、行粒度、主键、字段类型、约束、来源与使用方。优先匹配已有数据格式及导出器，不强制 C# 类型或某种标签式表头。
已发布标识保持稳定，不重排、不复用、不因展示排序变更 Id；Id 类型、起点、允许值由项目契约决定。删除记录需核查依赖并采用项目既有兼容策略。
外键说明目标表/字段及缺失含义，核对目标存在；数组、枚举、表达式按实际解析器支持格式，不自行创造编码。
client/server 是使用或导出归属，shared 是真实两端共享；服务端权威值与客户端展示值分清，避免误下发服务端专用字段。单机项目是否仅客户端导出依当前项目决定。
通过现有配置服务读取，不绕过生命周期/缓存约定，也不继承配置管理器来混入业务职责。生成文件是投影，Excel 是该链路实际源时不能直接手改生成配置。
