# 排版与导航
保留既有表头层次、字段开关与冻结区域，优先复用项目格式化器；没有固定八行头的工作簿不强制冻结八行。
字段提示和数据按内容自动换行、调整行高列宽，完整显示中文和长说明；Id、数值、描述、资源路径使用适合其内容的宽度，禁止显示被裁切。
外键提示设置可用的相对工作表/工作簿跳转，遵循当前文件格式支持的 HYPERLINK 或原生链接方式，并同步现有格式化器的引用映射。跳转仅用于策划阅读，不作为导出字段值。
颜色按真实分类设计并保留图例，不把五行元素等来源项目分类套到所有游戏。格式化只改显示，不改变字段、开关、Id 和数据值。
修改后重新读回中文和关键值，检查冻结、换行、链接目标及公式；再次运行格式化应保持数据与引用正确。
