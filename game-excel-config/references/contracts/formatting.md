# 排版与导航
保留既有表头层次、字段开关与冻结区域，优先复用项目格式化器；没有固定八行头的工作簿不强制冻结八行。
字段提示和数据按内容自动换行、调整行高列宽，完整显示中文和长说明；Id、数值、描述、资源路径使用适合其内容的宽度，禁止显示被裁切。
外键提示设置可用的相对工作表/工作簿跳转，遵循当前文件格式支持的 HYPERLINK 或原生链接方式，并同步现有格式化器的引用映射。跳转仅用于策划阅读，不作为导出字段值。
## Excel 数据颜色分类

制作或修改 Excel 时，数据区必须按实际业务类别配色，不能只给表头上色。先读取已有图例/格式化器的分类规则，保留同项目一致含义；没有规则时按已明确的字段值、枚举或记录类别建立映射。类别未明确先记录待确认，不根据行号、Id 范围或名称猜业务。

| 区域 | 分类方式 | 人类阅读目标 |
| --- | --- | --- |
| 数据记录 | 用浅色填充区分真实业务类别，如项目已有的配置类型、规则类型；同类记录跨 Sheet 使用一致颜色 | 一眼看出每条记录属于哪类；类别少时整行浅底色，类别多时只给分类单元格及记录名称着色 |
| 字段表头/说明 | 区分主键、外键、普通业务字段、备注及端侧归属；保留文字标签 | 看清哪些字段关联其他表、哪些仅用于制作说明 |
| 状态/备注单元格 | 明确已有测试、停用、待确认等状态时，使用提示色并写出状态及原因 | 辨认当前记录用途；着色本身不启用或停用配置 |

新项目可用淡蓝/淡绿/淡紫等易辨浅底色区分类别，主键用浅金、外键用浅青、制作备注用浅灰；这只是缺省配色建议，已有项目沿用自身规则。不把来源项目的元素类别套到所有游戏。正文使用高对比文字，不用红绿差异作为唯一辨识依据。

每张工作表放可见的“颜色 → 分类含义”图例，注明分类依据的字段/枚举；格式无法安全放说明区时用独立图例 Sheet，并先确认导出器确实跳过它。图例不能伪装成 VALUE 行或数据表。模块 config.md 同步简短配色映射；业务类别增删或变更时同步 Excel、图例与格式化器规则。

记录类别底色与字段类别冲突时，以记录类别保留数据区底色，字段角色在表头表示；状态在状态/备注单元格单独表示，不覆盖整行分类。无明确类别的普通记录保持中性底色，不能为好看随意分组。

## 显示与导出边界

纯配色/排版只改显示，不改变字段、端侧开关、Id、数据值或公式。现有格式化器若同时改端侧策略，不能作为“仅配色”操作直接执行；先拆分显示操作或审查实际变更。颜色不参与业务判断、端侧输出或解析，运行时仍读取真实字段。
修改后重新读回中文和关键值，检查冻结、换行、链接目标及公式；再次运行格式化应保持数据、引用和分类配色正确。保存后用对应 Excel 文件库读回填充色/样式和图例，核对同类同色、不同类别可辨；不要仅因脚本退出成功就声称配色已生效。仅配色变更应保持源值和公式不变，导出业务产物与变更前一致。
