# 配置流程

## 先判断、再读取或编写
1. 确认本模块需要配置；不涉及则说明并结束，不创建空表/空专题。
2. 查已存在源表、Sheet、字段格式、导出器/说明、生成目录和系统 Markdown/读取 API。文档足够且无冲突不扫描源码；操作工具前可定向读取工具入口/参数。
3. 已有完整配置直接读取和复用，说明真实接口、端归属及字段语义。读取不等于改表，没有变更不重建/导出。
4. 部分缺失只规划新增/修改项；完全缺失先在模块 config.md 按 [字段与导出规范](../contracts/fields-and-export.md) 写表用途、行粒度、字段注释、稳定 Id/外键、默认/空值、端归属和导出/读取映射。
5. 按表/字段列出“现状证据 → 读取复用/新增/修改/待确认 → 实际或拟定读取 API → 兼容影响与检查”处理清单。未确认数值和规则不猜测，保留待确认。
6. 仅查询或规划时交付清单/规划；已授权实际制作/修改则按下面链路编写。已有框架读取能力先给准确接口及细节，替代方案先按 [已有框架能力与重写选择](../../../game-system-development-planning/references/workflows/framework-reuse.md) 询问用户；既有选择不重复问。

## 实际编写与验证
1. 使用当前项目 .xls/.xlsx、标签/格式及既有工具；兼容已发布 Id 和字段语义，不改变生成规范来绕过限制。
2. 按清单写源表，逐字段注释同步规划与 Excel 说明；自动生成代码不可手改。
3. 查工具真实参数后执行格式化、导出、一致性检查和必要读表测试。没有工具先注明缺口，只有用户授权创建导出器时才实现。
4. 核对字段/默认、类型、重复和非法 Id、外键、端隔离、中文、公式、注释、布局/导航及生成结果；自动校验没有覆盖的项明确说明。编译输入变化按项目要求构建。
5. 实现及消费关系同步到系统/配置专题和原语言公开函数 API，记录真实基线与已运行结果；未执行不能标通过。计划 API 与已实现 API 分开，规划及 docs 维护按协作技能约定。
