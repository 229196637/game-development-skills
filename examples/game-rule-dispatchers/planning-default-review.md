# 规划默认仅文档与工单

本次修正规划入口：研究需求与相关现有代码 → 增补同步文档 → 写具体工单及依赖顺序 → 校验、交付后停止。文档与规划完成不是业务执行授权。只在用户明确要求执行本次工单时才实现、测试、验收；规划入口默认提示和操作图均体现停止分支。

Python 工具对进入 doing、勾选 done、记录测试/验收、设置 completed 要求 --execute；缺少模式标识立即拒绝并保持文件不变。标识不替代人类授权，调用者不能因为有工单就自行传入。init/update/relocate/check/list 用于默认规划；退回 todo/blocked/pending 可以修订规划，不驱动业务实现。

## 工具实际检查

隔离完成 9 次默认/显式模式操作：默认创建与检查通过，五种执行操作未传模式时被拒绝且工单字节不变；显式模式可进入 doing，但仍不能绕过未勾选或测试/验收门槛。没有创建业务实现文件，没有运行生产构建、业务测试或游戏。

## 独立默认试用

独立无历史上下文代理收到“为已有背包新增批量入库能力制定文档与规划”的请求，仅读取两个原始 Python 源文件与所需技能。生成模块设计资料、两份原语言 API 声明及两份同层级工单，文档 planning 检查和工单 check/list 通过。

两工单均为 todo、工作项未勾选、测试和验收未执行；两个输入源码 SHA256 前后一致。没有新增业务实现、运行构建或业务测试、启动编辑器、操作远程。原语言声明 AST 检查只含文档字符串与省略号，不是执行代码。

输出包含仓库外临时文档生成脚本与静态验证记录，不提交这些临时脚本。试用未建立独立 docs Git，明确记录该存储限制；未验证生产打包、运行时和全部图形渲染。接口形状/空列表/返回值的设计选择标明为技术提案，不伪装成用户已确认业务规则。

## 范围

工具不能监控外部代码写入或判断人类授权，仅提供显式模式约束；助手还必须遵守默认停止的技能说明。验证资料在仓库外隔离目录，未改生产项目。已有工单内容、同层级命名和历史记录机制保留。
