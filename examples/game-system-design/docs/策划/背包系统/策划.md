# 背包系统

## 目标
玩家拾取道具后，可在背包中使用消耗品。

## 核心流程

## 规则
| 条件 | 行为与结果 | 限制 |
| --- | --- | --- |
| 拾取道具 | 道具进入背包 | 容量与满包处理待确认 |
| 背包中存在消耗品 | 可以选择使用 | 具体效果由道具规则决定，尚待讨论 |
