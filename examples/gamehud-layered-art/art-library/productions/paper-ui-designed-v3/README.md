# 仙侠纸艺·适度纹饰UI

[新预览](index.html) · [原图与提示词记录](preview-record.json) · [全游戏定稿](../../art-direction.md) · [过于素净的v2对照](../paper-ui-functional-v2/README.md)

用户反馈v1装饰过多，v2过于简单没有游戏设计感。本轮保持已确认的纸艺融合配色/材质，控件改为窄分层边框、细云纹边带、折角和标题造型，内容区保留留白；不加入密集花枝或场景背景。使用内置imagegen实际参考认可原图生成两张整体效果图，原像素、提示词、观察和反馈归档。

仍是美术效果预览，未拆成独立控件，也不是可编辑界面。用户随后明确“这一套可以”，记录为认可的UI基线；独立控件及运行验收仍未完成。

[中国特色关闭按钮新讨论](../paper-ui-close-variants-v4/README.md)：整套风格沿用，本轮只进一步比较按钮与配套纹饰。
