# 执行工具约束验证

记录更新：2026-10-14 09:45:59 +08:00。在个人隔离目录执行，未对生产项目运行任务。原始测试程序和完整约束操作记录保留于隔离目录，不提交临时 Python。

## 实际结果

29 次顺序工具操作通过预期断言，另外启动两个独立进程同时领取同一工单：恰好一个成功，另一个拒绝；最后归还工单。连同重开后结果失效、报告丢失拒绝完成及恢复报告后的闭环，共验证 39 次操作。

| 场景 | 观察 |
| --- | --- |
| TODO 顺序 C → A → B，B 依赖 A | next 返回 C、A；显式先领 A 被拒绝，默认领取 C |
| 重复领取、其他 owner 修改 | 均被拒绝 |
| 工作项未勾选 | complete 拒绝 |
| 真实命令退出 3 | 保存 failed 报告/日志，run-test 返回 1；complete 拒绝 |
| 真实 unittest | 运行 1 项测试，退出 0，自动记录 passed 与独立报告 |
| 测试通过但缺验收 | complete 拒绝；逐项验收后完成 C |
| A 未完成就领取 B | 拒绝，不越过依赖 |
| 规划修订 doing 工单 | 拒绝，须执行者先 release |
| block → reopen → claim → release | 状态按预期恢复，历史结果失效 |
| 规划工具 complete --execute | 参数入口拒绝，执行能力已移出规划 |
| TODO 重复/错误 ID | 拒绝领取，前后所有工单 Markdown 字节摘要相同 |
| 重开/缺失报告 | 重开后旧 passed 不再有效；新测试通过后移走报告，complete 拒绝，恢复报告才完成 |
| 同时领取同一任务 | 一人获得任务，另一进程拒绝，未重复持有 |
| 既有六类工单补 order | 仅更新入口，镜像路径/历史/状态保留，check 通过 |

真实测试命令以 argv 列表、shell=False 运行。失败和通过均实际发生，报告不是预填 passed。上述 1 项简单 unittest 仅验证命令执行/证据闭环，业务正确性另见实际实现验证。

结构、路径、状态与报告存在检查不证明业务测试充分、人工验收真实；执行者必须核对证据与当前代码。任务状态仍以类 MD 为唯一来源，入口 TODO 不重复状态。
