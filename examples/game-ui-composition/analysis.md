# 布局分析

源图与设计分辨率均为 1920×1080，坐标映射比例 1。源图是素材审阅图：顶部标题和底部原尺寸说明不进入产品 UI；没有场景背景。

五底座显示 320×320，x 为 80、440、800、1160、1520，y 为 480。相邻间距 40。底座支撑点原坐标 (627,520)，显示全局 y=612.695。五主体用已有 v3 metadata 中 contact_anchor 对齐此支撑面；显示宽高分别 323、294、380、314、332，始终等比。

五按钮逻辑尺寸 320×545，位置从 (80,255) 开始，每次 x 加 360。主体 loader 透明外框可能超出逻辑矩形，但可见主体均约 266px 宽；1.08 倍状态最大按钮宽 345.6px，小于实例间距。实际点击区域和缩放最终须编辑器运行验证。

标题单独文本节点，显示在底座留白铭牌上：(x+60,636)，200×48，字号 32，浅金文字深绿描边。标题是“商店、任务、副本、好友、邮件”；不复制图片上的“商店主体”和技术尺寸文字。

盘点了原 GameHub/MainTapBtn、MainItem 与 CommoComponent/CommonConfirmButton。MainTapBtn 的 title/icon 和 selectScale/deselectScale 适合沿用，原 128px 主体位置与绘制底座不能直接匹配新素材，因此新建功能包 item/EntranceButton，复用其表现约定。没有更改公共包，跨功能公共化留给真正出现多个使用方时决定。

资源和实例详细关联见 [mapping.json](mapping.json)。底座不使用九宫格，浮岛绘画整体等比显示；主体也不拉伸。标题和视觉状态均不包含业务条件。
